CISA AutoS7

V2 - ALGORITMO UNIVERSAL

Funciona para qualquer serial + qualquer data

Digite exatamente 5 dígitos numéricos
Digite a data no formato DD/MM/AAAA

Algoritmo Universal (mod 17): Compatível com Autoclaves e Termodesinfectoras CISA com firmware AutoS7 V2.05.02. Usa número de série + dia + mês. Validado com 3 equipamentos diferentes.

CISA AutoS7

V1 - OFFSET FIXO (SERIAL 28617)

Algoritmo inicial - chave fixa por posição

Digite exatamente 5 dígitos numéricos
Digite a data no formato DD/MM/AAAA

Algoritmo V1 (Offsets Fixos): Cifra de substituição posicional. Concatena serial(5 dígitos) + data(DDMMAAAA) e aplica chave fixa [B,9,9,D,A,F,7,9,A,3,2,D,B] mod 16. Validado apenas para serial 28617.
